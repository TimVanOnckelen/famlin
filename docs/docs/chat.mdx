# Family chat

Chat gives each enabled family a shared conversation for quick messages that do not need to become a feed post. It is a family group chat, not a private one-to-one inbox.

Open **Chat** from the app navigation and select a family if you belong to more than one. You can send text or attach a photo or video, and reply to a particular message to keep a conversation in context. New messages appear automatically while chat is open; an unread badge helps you spot activity when you are elsewhere in the app.

Chat is available in the web and mobile apps when the family administrator has enabled it for that family. Only members of that family can access its chat.
