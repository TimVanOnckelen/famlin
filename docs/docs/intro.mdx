# Famlin

Private, self-hosted family updates app. Built with a Fastify + Prisma + Postgres backend, an Expo React Native mobile app, and a web app.

- **Self-hosted** — run it on your own server (e.g. Synology NAS, VPS, or home server).
- **Private by default** — a post is only visible to members of the families it was shared with, and a *circle* narrows that further to a smaller group within one family.
- **Mobile first** — iOS and Android app built with Expo.
- **Web app** — family members can also follow along in the browser, served at `/` from the same server.
- **Admin web UI** — manage users, groups, and server settings from `/admin`.
- **Multilingual** — English, Dutch, and Simplified Chinese (简体中文) across the apps, the web app, and the admin UI; each person picks their own language, defaulting to their device or browser language.

## Get the app

The official apps are free, and both ask for your server's address on first launch — the same download works for every self-hosted deployment.

- [**Download on the App Store**](https://apps.apple.com/us/app/famlin/id6786783660) (iOS)
- [**Get it on Google Play**](https://play.google.com/store/apps/details?id=be.xeweb.famlin) (Android)
- **Android without Google Play:** download the `.apk` from the [latest GitHub release](https://github.com/TimVanOnckelen/famlin/releases/latest) (under *Downloads*). It's signed differently from the Play version, so uninstall one before installing the other.

Family members who'd rather not install anything can open your server's address in a browser instead — every Famlin server also serves a full web app at `/`.

### Sharing from your phone's photo app

Looking at a photo in Photos, Google Photos, Files, WhatsApp or any other app? Tap **Share → Famlin**: the app opens a new post with that photo or video already attached, and you pick the family, write a caption and post as usual. On iPhone, Famlin appears in the share sheet as **Famlin Share** — if you don't see it, scroll the row of apps to the end, tap **More**, and switch it on.

- Several photos and videos shared together all go into one post. A post holds at most **10**; anything beyond that is skipped, and the app tells you how many.
- The same limits apply as when you pick photos inside the app: videos can be at most **2 minutes** long, and only photos and videos can be shared (not documents or links).
- If you're not signed in, Famlin asks you to log in first and then opens the new post with your photos still attached.
- If you're already writing a post, the shared photos are added to it.
- Photos go to the server the app is currently signed in to.

## Project structure

```
famlin/
  backend/                       Fastify API, Prisma schema, Docker image
    admin/                       React + Vite admin UI
  mobile/                        Expo React Native app
  web/                           React + Vite member-facing web app (served at /)
  packages/api-client/           shared API/data layer for mobile + web
  docs/                          Docusaurus documentation site
  website/                       static marketing landing page (famlin.app)
  docker-compose.yml             production/standard backend stack
  docker-compose.override.yml    local development with hot reload
```
