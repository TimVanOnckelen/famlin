# Famlin

Private, self-hosted family updates app. Built with a Fastify + Prisma + Postgres backend, an Expo React Native mobile app, and a web app.

- **Self-hosted** — run it on your own server (e.g. Synology NAS, VPS, or home server).
- **Private by default** — a post is only visible to members of the families it was shared with, and a *circle* narrows that further to a smaller group within one family.
- **Mobile first** — iOS and Android app built with Expo.
- **Web app** — family members can also follow along in the browser, served at `/` from the same server.
- **Admin web UI** — manage users, groups, and server settings from `/admin`.
- **Multilingual** — English, Dutch, Simplified Chinese (简体中文), European Portuguese (Português), and French (Français) across the apps, the web app, and the admin UI; each person picks their own language, defaulting to their device or browser language.

## Getting started

New here? [**Choose your installation**](./choose-installation.md) helps you pick the easiest way to run Famlin, whether you have a home server, a NAS, Home Assistant or nothing yet.

## Get the app

The official apps are free, and both ask for your server's address on first launch — the same download works for every self-hosted deployment.

- [**Download on the App Store**](https://apps.apple.com/us/app/famlin/id6786783660) (iOS)
- [**Get it on Google Play**](https://play.google.com/store/apps/details?id=be.xeweb.famlin) (Android)
- **Android without Google Play:** download the `.apk` from the [latest GitHub release](https://github.com/TimVanOnckelen/famlin/releases/latest) (under *Downloads*). It's signed differently from the Play version, so uninstall one before installing the other.

Family members who'd rather not install anything can open your server's address in a browser instead — every Famlin server also serves a full web app at `/`.
