The enriched, read-time view of an `ALBUM` post's `typeData` — computed
fresh on every read. An album's photos are its `Comment` rows with
`metadata.kind: "album_photo"` (see `Comment` below); this object
aggregates them rather than requiring a second fetch. The full photo
set lives on those comments' `metadata.photoUrls` — fetch the post's
comments to render the whole grid.
