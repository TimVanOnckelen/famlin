Per-family branding, set once per server by the admin. The palette is derived server-side (one implementation for every client): the brand color is darkened if needed so white text on `primary` meets WCAG AA, and a semantic post-type color (circle, milestone, trip) moves to an alternate hue when the brand would be hard to tell apart from it.
