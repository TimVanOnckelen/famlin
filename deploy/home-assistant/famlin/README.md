# Famlin

Private, self-hosted family updates: photos, videos, milestones, stories, trips
and comments, for your family only. This add-on runs the whole Famlin server
(including its own database) inside Home Assistant.

After starting the add-on, open the web UI to create the first administrator
account, then invite your family. See the Documentation tab for details,
including how to reach the server from outside your home.
