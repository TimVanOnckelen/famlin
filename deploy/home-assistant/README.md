# Home Assistant add-on

The Famlin Home Assistant add-on lives in its own repository:
https://github.com/TimVanOnckelen/famlin-ha-addon

It is kept there (and not here) so the code does not drift in two places. That
repository has its own CI, and a *Bump version* workflow that points the add-on
at a new Famlin release. User docs: https://famlin.app/docs/install-home-assistant
